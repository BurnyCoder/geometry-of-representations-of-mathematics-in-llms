# Deviations from the preregistration

Every change made to the analysis after the `prereg-v1` tag is listed here, with a date and a reason. Changes made *before* the tag are design decisions and appear in [`prereg.md`](prereg.md). The main ones:

- The primary tests are paired contrasts against the random-init twin. We moved away from partial regression after simulations showed it inflates type-I error.
- Families use Euclidean geometry.
- Common single words are flagged as polysemous.

| 2026-10-29 | **POST-HOC change to (b), after seeing the confirmatory model's output.** In the random-init twin this version gave ρ = 1.0 for the true order *and* a null 95th percentile of 1.0, i.e. a degenerate statistic. Cause: residualizing on all 11 items at once makes each held-out item's residual an exact linear combination of the training residuals (the residuals sum to zero), for the representation and the target alike, so a weakly regularized ridge "predicts" any order (data leakage). Final version: cross-validated confound regression (Snoek, Miletić & Scholte 2019, *NeuroImage* 184:741, doi:10.1016/j.neuroimage.2018.09.074), i.e. the covariate regression is fitted on the training items of each fold and applied to the held-out item. Simulation (40 runs each): 5% rejections under the frequency-only null, 2.5% under large-scale pure noise (a twin-like regime), 100% power with the covariate a noisy copy of the order or unrelated. Results of the leaky version for the confirmatory model are kept for transparency: ring chain ρ = 0.83 (p = .010), space chain 0.86 (p = .003), twin 1.00 / 0.91 with null95 = 1.0.
