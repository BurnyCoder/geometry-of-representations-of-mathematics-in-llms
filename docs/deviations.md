# Deviations from the preregistration

Every change made to the analysis after the `prereg-v1` tag is listed here, with a date and a reason. Changes made *before* the tag are design decisions and appear in [`prereg.md`](prereg.md). The main ones:

- The primary tests are paired contrasts against the random-init twin. We moved away from partial regression after simulations showed it inflates type-I error.
- Families use Euclidean geometry.
- Common single words are flagged as polysemous.

| Date | Change | Reason | Affects |
|---|---|---|---|
| 2026-10-29 | Field → super-tree branch assignment for H-A2 written into `configs/fields.yaml` (`branch:`): algebra & number theory = {group, ring/module, commutative algebra, Lie/representation, number theory, algebraic geometry}; geometry & topology = {general topology, algebraic topology, differential geometry}; analysis = {real/complex, functional}; foundations & discrete = {set theory/logic, category theory, graph theory}; applied = {probability/statistics, numerical analysis, game theory}. | `prereg-v1` named the five branches but not the membership; fixed before any H-A2 statistic was computed. | H-A2 |
| 2026-10-29 | Gemma-4-E2B loaded with its per-layer-embedding (PLE) lookup table and unused audio/vision towers kept in CPU RAM and the text decoder on GPU (`offload_ple`, explicit placement + device hooks around the PLE lookup), and run under its own config `configs/gemma.yaml`. A first attempt with an accelerate `device_map` failed ("Cannot copy out of meta tensor": accelerate treats `cpu` entries as offload-to-GPU-on-use). | The full multimodal checkpoint (5.1B params) does not fit in 8 GB; the decoder computation is unchanged. Separate config so the three Qwen robustness models could be analysed while Gemma was debugged. | Robustness |
| 2026-10-29 | Causal-test specifics fixed before running it: task = "which is more general, a A or a B?" over all ordered pairs of the ring and space chains, both answer orders; gate = baseline accuracy ≥ 0.70; noise in the top-2 PCA subspace of the other chain items at the concept-final tokens, σ = s·RMS-spread/√2 for s ∈ {1, 2, 4}; control = 5 random 2-D subspaces with the same σ. | `prereg-v1` specified the logic (gate, held-out fit, random-subspace control) but not the exact task wording, threshold and noise scales. | H-B causal |
| 2026-10-29 | POST-HOC statistic `closure_far` = d(first,last)/d(first,middle) with the 5th percentile of its order-permutation null, added after seeing that the positive control (days/months) met the closure and circle-ρ criteria but not circle-ρ > line-ρ at the pre-registered layer. | The pre-registered closure ratio is ≈1 both for circles and for structureless point clouds; `closure_far` separates closed loops from open chains. Reported as post-hoc only; pre-registered criteria are reported unchanged. | H-B |
| 2026-10-29 | POST-HOC phase `posthoc`: field-map ρ as a function of the number of removed top PCs (all-but-the-top k ∈ {0,1,2,3,5,10,20,40}) and field η² per PC. | The pre-registered ABTT variant (k = d/100 = 20) reversed the sign of ρ; the sweep tests whether the map lives in a few rogue dimensions or in the dominant semantic components. Exploratory. | H-A1 |
| 2026-10-29 | POST-HOC diagnostic `pc_plane_cycle` (fraction of items whose angular successor in the top-2-PC plane is the true next item, with an order-permutation null, all layers). | The pre-registered positive-control criterion (full-space circle-ρ > line-ρ at layer 12) FAILED for days/months; per the prereg we debugged the pipeline before interpreting. Engels et al. identified circles in low-dimensional projections, so we tested the 2-D PC plane: days and months form perfect cycles there at most layers in the trained model and not in the random-init twin, so the pipeline works and the full-space template criterion was insensitive. The failure of the pre-registered criterion is reported as such. | H-B |
| 2026-10-29 | POST-HOC matched clustering: LOO nearest-centroid accuracy over 200 random 4-field subsets of math fields vs the 4 control fields. | The pre-registered specificity comparison (17 math vs 4 control fields) confounds domain with number of classes. Exploratory. | H-A1c |
