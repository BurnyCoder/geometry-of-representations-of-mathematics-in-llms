# Deviations from the preregistration

Every change made to the analysis after the `prereg-v1` tag is listed here, with a date and a reason. Changes made *before* the tag are design decisions and appear in [`prereg.md`](prereg.md). The main ones:

- The primary tests are paired contrasts against the random-init twin. We moved away from partial regression after simulations showed it inflates type-I error.
- Families use Euclidean geometry.
- Common single words are flagged as polysemous.

| 2026-10-29 | **Second plan audit — analyses specified here before any of them was computed.** (a) *Mathlib validation of the judges (plan H-A4, the user's chosen ground truth "Judges + Mathlib").* Each math concept is matched to a Lean declaration in Mathlib4 (commit pinned in `configs/mvp.yaml` and recorded in `results/mvp/mathlib.json`), first via Mathlib's curated English-name maps `docs/overview.yaml` and `docs/undergrad.yaml`, then (multi-word names only) via an exact CamelCase match to a `structure`/`class`/`def`/`abbrev`/`inductive` name (`compact space` → `CompactSpace`, also `Is…`); ambiguous names are dropped. Depth = longest chain of Mathlib imports below the defining module. Primary statistic: Spearman ρ between the mean judge rating and depth over matched concepts, 2,000-resample concept bootstrap CI. Prediction ρ > 0; the judges count as validated only if the CI excludes 0. Coverage (fraction matched) is reported per field. (b) *Chain frequency control (plan H-B), for the line-type chains.* First specification: LOO order ρ after residualizing the LOO predictions and the true ranks on [wordfreq Zipf, model token count], with an order-permutation null. **Replaced before any real data was analysed:** a simulation in which the representation encodes only a frequency that tracks the order rejected 42% of the time at α = .05, because permuting the order also breaks the order–frequency link that this null hypothesis keeps. Final version: residualize the representation *and* the ranks on [1, Zipf, token count], then the Spearman ρ of LOO ridge predictions of the residual order from the residual representation, with an order-permutation null (300). In the same simulation it rejected 2.5% (1/40) under the frequency-only null, and had 92.5% power when the representation encodes the order and the covariate is a noisy copy of it (100% with an unrelated covariate). Criterion as in the plan: p < .05. (c) *Lattice items from the plan not yet analysed (exploratory).* Associative quasigroup, a semantic-collapse probe (a non-empty one is a group): collapse is supported if d(AQ, group) < d(AQ, quasigroup) in the trained model and the ratio d(AQ, group)/d(AQ, quasigroup) is lower than in the twin. Inverse semigroup: nearest lattice neighbours, descriptive. Partial-operation lattice (semigroupoid, small category, groupoid vs semigroup, monoid, group; bits total/identity/divisible) with the existing offset tests. Lattice-like held-out pairs (semilattice → bounded semilattice, lattice → bounded lattice) for the identity-direction transfer test. Group-like offsets recomputed (i) on mean-pooled tokens (plan test 1) and (ii) after projecting out the token-count direction fitted on all family items (plan test 2; a one-direction analogue of Li et al.'s LDA distractor removal, arXiv:2410.19750 §3). New family items are appended after the existing ones (batch size 1), so earlier activations and results are unchanged. | Plan items found missing or partial in the second audit. | H-A4, H-B, H-B2 |
| 2026-10-29 | **POST-HOC change to (b), after seeing the confirmatory model's output.** In the random-init twin this version gave ρ = 1.0 for the true order *and* a null 95th percentile of 1.0, i.e. a degenerate statistic. Cause: residualizing on all 11 items at once makes each held-out item's residual an exact linear combination of the training residuals (the residuals sum to zero), for the representation and the target alike, so a weakly regularized ridge "predicts" any order (data leakage). Final version: cross-validated confound regression (Snoek, Miletić & Scholte 2019, *NeuroImage* 184:741, doi:10.1016/j.neuroimage.2018.09.074), i.e. the covariate regression is fitted on the training items of each fold and applied to the held-out item. Simulation (40 runs each): 5% rejections under the frequency-only null, 2.5% under large-scale pure noise (a twin-like regime), 100% power with the covariate a noisy copy of the order or unrelated. Results of the leaky version for the confirmatory model are kept for transparency: ring chain ρ = 0.83 (p = .010), space chain 0.86 (p = .003), twin 1.00 / 0.91 with null95 = 1.0. The control runs as its own phase (`chainfreq` → `chain_frequency.json`), so the shapes phase and its results are untouched. | Data leakage made the statistic degenerate in the random-init twin. | H-B |
