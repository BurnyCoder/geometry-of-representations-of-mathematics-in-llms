The angle prediction supplies a deterministic inequality. The field-map decision requires both the field-label permutation and a positive paired confidence interval. The historical additional input for H-A1 counted nonpositive resampled differences in an ordinary bootstrap centered on the sample estimate. Giving that slot a value of one preserves family size without treating this tail as a calibrated null p-value. Report both adjustments. For the ring chain, 411,890 of 39,916,800 orderings attained its Robinson score, for exact p = 0.01032. This tests Robinson alone. The registered conjunction uses the larger of the Robinson and LOO permutation p-values and also requires a trained score above the twin. [Holm](https://www.jstor.org/stable/4615733) · [Hall & Wilson](https://doi.org/10.2307/2532163) · [intersection-union tests](https://doi.org/10.1080/00401706.1982.10487790).

The ring labels assume unital rings after “rng” and commutative domains. Their consecutive head nouns supply a rival explanation. Within the six domain names the exact MVP Robinson p was 0.3194. For the space sequence the corresponding within-block values were 0.0167 and 0.0167 (exploratory, unadjusted). “Regular” and “normal” require the stated separation conventions. A metrizable topology admits a compatible metric. Choosing a metric, a norm or an inner product adds structure. The sequence orders the configured names and forgetful relationships. It is not a literal inclusion chain of identically typed objects. A Robinson score assesses an ordering of distances and does not determine intrinsic dimension. [Family definitions](../../configs/families.yaml) · [Munkres, §§20–21 and 31](https://people.math.ethz.ch/~dkosanovic/24-FS/Munkres-Topology.pdf).

Both calendar controls failed the original full-space rule at all five trained checkpoints. The protocol instructed the investigators to declare the pipeline broken and debug before interpreting other results. The later diagnostics do not retroactively meet that control. A claim that the entire preregistered battery passed is untenable. The original angle prediction failed too. The minimum circular template distance, the angular-neighbour score in a projection, and a closed loop in a selected plane are different tests. An open arc can have perfect angular ordering. The later search covers the ten coordinate planes from PC1 through PC5, leaving arbitrary rotated planes and other subspaces unresolved. The failed control particularly limits negative inferences about circularity. The primary field-map statistic has its own independent external target, label null and trained–twin contrast. [Frozen rules](../../docs/prereg.md) · [post-hoc plane rule](../prereg_addendum_3d.md) · [Engels et al., §§4–5](https://arxiv.org/html/2405.14860v3).

In the coordinatewise partial order, commutative magma and unital magma have incomparable minimal upper bounds, commutative loop and commutative monoid. No sampled join exists. For offsets, subtract the endpoint with a zero from the endpoint with a one while holding the other required bits fixed. A single random bijection of all thirteen vertex labels preserves every edge intersection and orientation in the post-hoc reference. The ledger reports the 20,000-draw plus-one p-values beside the historical Holm verdicts. Static word-form baselines and nonce controls can yield aligned offsets. ## Reproduction and publication

Use the repository at this revision and its locked environment (`uv sync --frozen`). Install Poppler’s `pdftotext` for the published PDF check. Set `MATHGEOM_ARTIFACTS` to the artifact directory or use `artifacts/` in the checkout. The twenty trained/twin field and family caches, family index, five prompt logs, category file and embedding matrix were checked against their Hub object hashes (text files allow standard Git newline normalization). The [pinned dataset input revision](https://huggingface.co/datasets/BurnyCoder/geometry-of-mathematics-in-llms/tree/697c42459a738db888157e9d1fd1aee49a4d030c) supplies `acts/`, the judge and final causal logs, and the audit input files. Place `acts/` under the artifact directory. In the checkout’s `logs/`, place the judge and final causal logs linked above and the three original `*_extract_prompts.jsonl` files starting with `20261029-062417`, `20261029-071103` and `20261029-085551`. Copy the category JSON and saved Qwen embedding matrix from `audit_inputs/` into the artifact directory. Place the [published fastText archive](https://fasttext.cc/docs/en/english-vectors.html) named `wiki-news-300d-1M.vec.zip` in its `baselines/` subdirectory. Check out [the exact Mathlib revision](https://github.com/leanprover-community/mathlib4/tree/4bc4670bf916c8dc2ede840e3ead86301e52a40d) in its `mathlib4/` subdirectory. Only Lean sources are needed.

```sh
uv run --no-sync python -m mathgeom.verification.run
```

This command reconstructs the evidence and checks each recorded value in the [verification JSON](../../results/scientific_audit/verification.json). To regenerate publications from the reviewed results and saved display coordinates, run `uv run --no-sync python -m mathgeom.verification.publish` with Pandoc, XeLaTeX and the study fonts installed. The [paper](../../paper/paper.pdf), [explorer](https://burnycoder.github.io/geometry-of-representations-of-mathematics-in-llms/) and [dataset card](https://huggingface.co/datasets/BurnyCoder/geometry-of-mathematics-in-llms) use the reviewed comparison. Historical protocols, initial candidate matches and raw logged observations retain their original meaning.
